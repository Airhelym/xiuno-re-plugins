# xiuno-re-plugins

这里存放一些适配\/二次开发\/新制作的 xiunobbs 插件，优先考虑在 xiuno-re 上的可用性。

适配\/二次开发：

| 名称 | 目录 | 适配 |
| ----- | ----- | ----- |
| 消息 | huux_notice_re | 使用新的样式 |
| 搜索插件 | xn_search_re | 增加模糊搜索和用户搜索功能 |
| APP 底部栏 | git_appdock_re | 调整底栏高度，避免遮挡 |
| 二级导航 | xn_nav_2_re | 增加部分设置项 |
| 精华主题 | xn_digest_re | 样式优化 |
| 帖子收藏 | haya_favorite_re | 样式优化，修复原插件在特定情况下破坏前台布局的问题；增加部分组件的显示开关 |
| 帖子点赞 | haya_post_like_re | 样式优化；增加部分组件的显示开关 |
| 附件管理器 | haya_attach_re | 样式优化 |

大幅改动\/新制作（仍在开发中）：

| 名称 | 目录 | 功能 |
| ----- | ----- | ----- |
| 私信 | xnre_pm | 聊天式界面，可查看与用户的历史私信消息；可设置撤回时间、发信频率等 |
| RSS | xnre_rss | 全站和板块 RSS 订阅生成器，支持自定义名称、版块选择和自动更新规则 |

>注：如果上传后发现插件已经安装，请手动卸载对应插件后再安装，避免意外情况发生
